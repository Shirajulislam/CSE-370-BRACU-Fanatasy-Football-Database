# Attribution and licensing

This file records the provenance and licensing points that should be considered when maintaining or redistributing this repository. It is not legal advice.

## Upstream project

The BRACU CSE-370 project was based on the upstream [Fantasy-Football-Database project by edavis25](https://github.com/edavis25/Fantasy-Football-Database).

The recovered archive's root README links to that project, and its SQLite schema contains attribution to **Eric Davis** and **Mark Eidsaune**. Some source files also contain author comments. Preserve these notices and keep the upstream relationship clear in documentation.

## BRACU adaptation

The BRACU repository contains an adaptation of the upstream work. Before making further releases, maintainers should keep a record of:

- which files or features were changed for the BRACU course project;
- the names and contributions of BRACU group members, after confirming them with the group;
- the scope of permission to redistribute the upstream code and group contributions; and
- any conditions attached to that permission.

Do not present the complete codebase as wholly original work by one person.

## Third-party components

The recovered archive contains a dashboard based on the SB Admin / Bootstrap template and bundled front-end libraries and assets. The file dashboard/LICENSE names Blackrock Digital LLC and applies to the SB Admin template; it should not be treated as the licence for every component in this repository.

Before choosing a root-level licence, review the notices and terms for each bundled library, template, Java dependency, R package, image, font, and other asset.

## Data provenance

The database and CSV files contain historical football data. A data source being publicly accessible does not automatically mean that its contents may be redistributed. Document the original source for each dataset and confirm the applicable terms before adding recovered databases, CSV exports, or scraped output to a public release.

## Project-wide licence status

No root-level licence covering the complete project was present in the recovered archive or the current repository root when this review was prepared. Do not copy dashboard/LICENSE to the root or add a blanket licence until the project code, upstream code, third-party components, and datasets have been reviewed for licence compatibility and redistribution rights.
